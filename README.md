# Spatiotemporal-Crime-Count-Predictor
This project utilizes Apache Spark’s PySpark to analyze the reported crimes dataset in the city of Chicago and create a spatiotemporal crime count predictor using machine learning algorithms. The primary objective of this project is to examine the effect of using the full dataset, versus synopsis, of various sizes, to train the model and highlight the advantages and tradeoffs of each method, in the context of Big Data Analytics and traditional Regression models.
